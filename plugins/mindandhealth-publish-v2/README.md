# mindandhealth-publish-v2

Acompañamiento editorial conversacional para las publicaciones de Pablo Rodríguez López en mindandhealth.org. Una conversación exploratoria puede cristalizar en un borrador Markdown que se revisa dentro del chat.

El método está adaptado a ese proyecto y a su voz editorial. No publica contenidos ni escribe en el vault de Obsidian. El autor revisa el resultado y decide qué copiar o publicar.

## Uso y ejemplos

Selecciona la skill `mindandhealth-publish-v2` en Claude. En Claude Code puedes usar `/mindandhealth-publish-v2:mindandhealth-publish-v2`.

1. «Me ronda esta idea: cómo cambia nuestra relación con la incertidumbre cuando conversamos con una IA. Pensemos sus tensiones antes de redactar».
2. «Saca un canvas en español con lo que llevamos, en registro de ensayo y extensión breve».
3. «A partir de este artículo que te pego, prepara una propuesta de newsletter para LinkedIn. Mantén la atribución de las citas: [artículo]».

Los borradores permanecen en el chat. Los cambios se realizan ante una petición o una sugerencia aprobada. Los derivados, incluidos los prompts de imagen 1570:880, se preparan bajo petición. No se generan imágenes.

## Acceso y límites

Si el entorno permite leer una carpeta del vault que el usuario ha conectado o indicado, pueden consultarse artículos para verificar enlaces o patrones editoriales. Sin acceso, el usuario debe aportar los textos. La consulta de URLs y fuentes depende de las herramientas y permisos del entorno. La delegación a subagentes es opcional y depende de que el entorno disponga de ese mecanismo.

El contenido requiere revisión humana. No se deben inventar citas, artículos ni URLs.
